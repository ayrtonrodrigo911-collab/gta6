# GTA VI - DevClub Character Selector 🌴🚗

Um seletor de personagens temático do GTA VI, desenvolvido durante o DevClub. O projeto oferece uma experiência cinematográfica com animações avançadas, sistema de partículas e suporte para upload de fotos personalizadas.

## 🚀 Tecnologias Utilizadas

*   **HTML5** - Estrutura semântica.
*   **CSS3** - Estilização moderna com animações e responsividade.
*   **JavaScript (Vanilla)** - Lógica de seleção e manipulação de DOM.
*   **GSAP (GreenSock Animation Platform)** - Animações cinematográficas e transições suaves.
*   **Canvas API** - Sistema de partículas dinâmico para o fundo.

## ✨ Funcionalidades

*   **Seleção de Lendas:** Escolha entre Lucia, Jason e lendas clássicas como CJ, Tommy Vercetti, Claude Speed e Franklin Clinton.
*   **Upload Personalizado:** Botão "YOU" que permite ao usuário carregar sua própria foto e entrar no universo GTA.
*   **Experiência Dinâmica:**
    *   Transições de cores de partículas baseadas no personagem selecionado.
    *   Animações de "respiração" (idle) nos personagens.
    *   Troca dinâmica de backgrounds e logos da Rockstar/Games.
    *   Efeitos sonoros visuais (Glow e sombras projetadas).
*   **Totalmente Responsivo:** Design adaptado para Desktop, Tablets e Smartphones.

## 📸 Preview

O projeto utiliza um visual premium inspirado na estética do próximo grande lançamento da Rockstar Games, com fontes icônicas e gradientes vibrantes.
